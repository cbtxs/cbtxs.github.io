## Open-Source Contributions

Core developer of [FEALPy](https://github.com/weihuayi/fealpy), an open-source library of foundational algorithms for CAX applications. My main responsibility is developing finite element modules, including:

- $\mathrm{BDM}$, $\mathrm{RT}$, and $\text{Nédélec}$ elements
- $\text{Hu–Zhang}$ elements
- $C^m$-smooth elements
- $H^1$-conforming and nonconforming virtual element methods
