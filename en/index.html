Appointments

  • 2025.01–2025.05: Visiting scholar, Department of Mathematics, University of California, Irvine (UCI).

Research Skills

  • Proficient in Python and C++.
  • Familiar with numerical methods, including finite element and virtual element methods.

Research Interests

  • New finite element methods, including tensor and distributional finite elements
  • Theory and applications of virtual element methods
  • Numerical simulation of gravitational waves
  • Development of industrial simulation software

Open-Source Contributions

Core developer of FEALPy, an open-source library of foundational algorithms for CAX applications. My main responsibility is developing finite element modules, including:

  • $\mathrm{BDM}$, $\mathrm{RT}$, and $\text{Nédélec}$ elements
  • $\text{Hu–Zhang}$ elements
  • $C^m$-smooth elements
  • $H^1$-conforming and nonconforming virtual element methods
