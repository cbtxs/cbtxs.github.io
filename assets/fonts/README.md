# English typography

- Source Serif 4: body text, upright and italic variable fonts.
- Source Sans 3: navigation and headings, upright variable font.

Source files are from the Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/sourceserif4
- https://github.com/google/fonts/tree/main/ofl/sourcesans3

The original TTF files were converted to WOFF2 using fontTools, without
subsetting or changing their names or outlines. Each font family's SIL Open
Font License is included in its directory. The website serves these files
locally; English pages do not need Google Fonts to load their text fonts.
